### **What is Python?**
Python is a **programming language**—a way to tell a computer what to do, just like giving instructions to a robot friend.

Think of it like **cooking**:
- You write a recipe (code) in Python.
- The computer follows the steps (executes the code).
- You get a delicious result (a program that works!).

---

### **Why Use Python?**
1. **Easy to Learn** – Simple words and rules (like English, not math symbols).
2. **Versatile** – Can make websites, games, apps, analyze data, and more.
3. **Free to Use** – Anyone can download and use it without paying.

---

### **Basic Concepts with Examples**

#### **1. Printing (Saying Something)**
Just like talking to someone, you can make the computer say things.

**Example:**
```python
print("Hello, World!")
```
**Output:**
```
Hello, World!
```
*(This tells the computer to display "Hello, World!" on the screen.)*

---

#### **2. Variables (Storing Information)**
Variables are like **boxes** where you store things (numbers, words, etc.).

**Example:**
```python
name = "Alice"  # Store "Alice" in a box called "name"
print("Hello,", name)
```
**Output:**
```
Hello, Alice
```
*(Here, `name` is a box holding "Alice".)*

---

#### **3. Math (Doing Calculations)**
Python can do math like a calculator.

**Example:**
```python
a = 5
b = 3
sum = a + b  # Add 5 and 3
print("The sum is:", sum)
```
**Output:**
```
The sum is: 8
```
*(`sum` is a box holding the result of `5 + 3`.)*

---

#### **4. If-Else (Making Decisions)**
Like asking "Is it raining?" and deciding what to wear.

**Example:**
```python
age = 18
if age >= 18:
    print("You can vote!")
else:
    print("You can't vote yet.")
```
**Output:**
```
You can vote!
```
*(If `age` is 18 or more, it says "You can vote!". Otherwise, it says "You can't vote yet.")*

---

#### **5. Loops (Repeating Tasks)**
Loops help do the same thing over and over, like counting from 1 to 5.

**Example:**
```python
for i in range(1, 6):  # Count from 1 to 5
    print(i)
```
**Output:**
```
1
2
3
4
5
```
*(`range(1, 6)` means "start at 1, go up to 5".)*

---

#### **6. Functions (Reusable Instructions)**
Functions are like **shortcuts** for repeating tasks.

**Example:**
```python
def greet(name):  # A function called "greet"
    print("Hello,", name)

greet("Bob")  # Call the function
```
**Output:**
```
Hello, Bob
```
*(`greet()` is a shortcut to say hello to someone.)*

### **Что такое Python?**
Python — это **язык программирования**, который помогает компьютерам выполнять задачи по нашим инструкциям. Он похож на обычный язык, но компьютер его понимает.

**Аналогия:**
Представь, что ты даёшь команду роботу:
- *"Возьми яблоко"* → Робот берёт яблоко.
- *"Положи его в корзину"* → Робот кладёт яблоко в корзину.

Python — это как **"язык команд"**, который ты пишешь в текстовом файле, а компьютер выполняет эти команды.

---

### **Как работает Python?**
1. **Ты пишешь код** (команды) в текстовом файле с расширением `.py`.
   Пример:
   ```python
   print("Привет, мир!")
   ```
   Это команда компьютеру: *"Напечатай 'Привет, мир!' на экране"*.

2. **Компьютер выполняет код** по порядку.
   - Сначала читает `print("Привет, мир!")`.
   - Затем показывает текст на экране.

3. **Python прощает ошибки** (по сравнению с другими языками).
   Например, если ты напишешь `prnt` вместо `print`, он скажет: *"Ой, такой команды нет!"*, но не ругается сильно.

---

### **Примеры кода на Python**

#### **1. Приветствие**
```python
print("Здравствуй, друг!")
```
**Что делает:**
Выводит на экран текст *"Здравствуй, друг!"*.

---

#### **2. Сложение чисел**
```python
a = 5
b = 3
c = a + b
print(c)  # Выведет: 8
```
**Что делает:**
- `a = 5` → Запоминает число 5 в "ящике" с названием `a`.
- `b = 3` → Запоминает число 3 в "ящике" `b`.
- `c = a + b` → Складывает `a` и `b`, результат (8) сохраняет в `c`.
- `print(c)` → Печатает `8`.

---

#### **3. Ввод данных от пользователя**
```python
name = input("Как тебя зовут? ")
print("Привет, " + name + "!")
```
**Что делает:**
- Спрашивает у пользователя имя (`input`).
- Сохраняет ответ в "ящике" `name`.
- Печатает: *"Привет, [имя]!"*.

**Пример работы:**
```
Как тебя зовут? Аня
Привет, Аня!
```

---

#### **4. Условная логика (если... то)**
```python
age = 18
if age >= 18:
    print("Ты взрослый!")
else:
    print("Тебе ещё рано.")
```
**Что делает:**
- Проверяет, больше ли `age` (возраст) 18.
- Если **да** → Печатает *"Ты взрослый!"*.
- Если **нет** → Печатает *"Тебе ещё рано"*.

---

#### **5. Цикл (повторять действие)**
```python
for i in range(3):  # Повторить 3 раза
    print("Ура!")
```
**Что делает:**
Печатает *"Ура!"* три раза:
```
Ура!
Ура!
Ура!
```
