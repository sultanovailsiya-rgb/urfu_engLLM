Задания разложены по папкам — одно задание на папку. Внутри каждой папки свой README с порядком проверки.

| Папка | Задание | Статус |
|---|---|---|
| [`01_MCP_Lab/`](01_MCP_Lab/) | MCP Experiment Lab — эксперименты с MCP-сервером (prompt, resources, tools, транспортные протоколы), модификация сервера и агента | готово |
| [`02_Agent_Guards/`](02_Agent_Guards/) | Agent Guardrails — защита агента: PII-детекция и анализ безопасности через LLM Guard | готово |
| [`03_Giskard/`](03_Giskard/) | RAG Security Testing с Giskard — тестирование LLM: метрики качества, поиск уязвимостей, собственные тесты, сравнение моделей | готово |
| `04_` | задание будет добавлено | — |

## Как смотреть каждое задание

Общий порядок: сначала отчёт, потом логи экспериментов, потом код.

1. **Отчёт** — `Отчёт.docx` (та же версия текстом — `Отчёт.md`): что сделано, результаты, таблицы, выводы.
2. **Логи** — папка `logs/`: протоколы прогонов; в README задания описано, какой файл за что отвечает.
3. **Код** — все изменения помечены комментариями прямо в файлах («ИСПРАВЛЕНО», «ЗАМЕНА», «ИЗМЕНЕНО»).

## Как запускать

Каждое задание самодостаточно: в его папке лежит README с командами запуска и свои зависимости (`pyproject.toml`, `uv.lock`). Общее требование: Python 3.12+, [uv](https://docs.astral.sh/uv/).

Ключи моделей задаются переменными окружения (например, `MISTRAL_API_KEY`) — в код ключи не встраиваются.
